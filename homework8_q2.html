Web Evaluation

Homework 8 Question 2

1) Appealing Website: Epic Games Store

a) URL: https://store.epicgames.com/en-US/

b) Does this page use tables? I didn't see a table on this page. The page uses boxes and sections for games and offers.

c) Does this page use CSS? Yes, it uses CSS for layout, colors, text style, and buttons.

d) Is this page appealing or unappealing? This page is appealing to me.

  • The page looks clean and modern.
  • The text is easy to read.
  • Games are grouped in clear sections.

2) Unappealing Website: itch.io

a) URL: https://itch.io/

b) Does this page use tables? I didn't see a table. It uses many lists, cards, and links.

c) Does this page use CSS? Yes, it uses CSS for page layout, text sizes, colors, and spacing.

d) Is this page appealing or unappealing? For me, this page is unappealing in this comparison.

  • There is too much information on one page.
  • The page feels crowded.
  • Important parts are not easy to find quickly.

e) If this page is unappealing, what would you do to improve it?

  • Show fewer sections at the top.
  • Add more empty space between sections.
  • Make one strong featured area first.
