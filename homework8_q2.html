Web Evaluation

Homework 8 Question 2

1) Appealing Website: Tesla

a) URL: https://www.tesla.com

b) Does this page use tables? No, I didn't see any tables on this page. The page layout was created using boxes to display the cars.

c) Does this page use CSS? Yes, there are animations, fonts, and high-quality visual transitions between sections.

d) Is this page appealing or unappealing? This page is very interesting and beautiful to me.

  • The visuals are very beautiful and high quality.
  • It is easy and convenient to use.
  • It allows the user to find what they are looking for without overwhelming them with too much text.

2) Unappealing Website: Mynet

a) URL: https://www.mynet.com

b) Does this page use tables? Yes, the page uses multiple tables to organize different news categories, stock market data, and weather information all on a single page.

c) Does this page use CSS? Yes, it uses CSS, but the design is very cluttered and disorganized. It looks confusing because there are too many things at once.

d) Is this page appealing or unappealing? For me, this page is unappealing.

  • The page is full of ads, which is very distracting.
  • It is visually weak and does not provide an easy search experience.
  • The ease of use is worse compared to other modern websites.

e) If this page is unappealing, what would you do to improve it?

  • I would remove the excessive number of ads to simplify the look.
  • I would increase the space between the news items so the user can breathe.
  • I would simplify the navigation menu and use larger, higher-quality images for the main news.
